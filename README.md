# BEELINE

- This repository was copied from BEELINE. The documentation is available at: [https://murali-group.github.io/Beeline/](https://murali-group.github.io/Beeline/).

- Cite of original article: Pratapa, A., Jalihal, A.P., Law, J.N., Bharadwaj, A., Murali, T. M. (2020) "Benchmarking algorithms for gene regulatory network inference from single-cell transcriptomic data." _Nature Methods_, 17, 147–154.

- This pipeline was used to run methods and evaluations of Gene Regulatory Netowrks based on scRNAseq. We have introduced two methods: WGCNA and INFERELATOR. Aditionally we have adapted the pipeline to accept SINGULARITY, a common container system used in high performance computer (HPC) clusters.
